# Translations

All 16 languages are complete for every key (checked by `backend/tests/test_i18n.py`).

Translations were written and reviewed by AI translation agents, not yet by native speakers.
Points a native speaker should check first:

- Name of Movie assembly: ja 仮編集, ko 가편집, zh 影片粗剪, hi फ़िल्म असेंबली.
- Words-per-minute advice quotes English rates; for ja/zh the rate is not measured.
- Telugu "డైలాగ్" vs "సంభాషణ" and Tamil "வசனம்" vs older wording for dialogue: pick one.
- Kannada "ಕುತೂಹಲ" for tension; Telugu "హోదా" / Kannada "ಹುದ್ದೆ" for account role.
- Arabic room tone / take / low-key-high-key wording; Portuguese "GC" for lower thirds.
- Korean particles after clip names ("“{clip}” 클립이").
